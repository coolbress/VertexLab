# Quickstart

The `vertex-lab` package is the future home of the user-facing CLI and app wrapper for the workspace.

## Current behavior

The CLI entrypoint exists, but it is still a stub while the first real app workflows are being implemented.

```bash
uv run --package vertex-lab vertex-lab
```

When the orchestration layer ships, this page will become the package-level quickstart for launching and operating the full VertexLab experience.

## In the meantime

For the production-ready data workflow today, use:

- [vertex-forager quickstart](https://coolbress.github.io/VertexLab/vertex-forager/tutorials/quickstart/)
