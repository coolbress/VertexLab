# vertex-lab

`vertex-lab` is the user-facing orchestration package for the VertexLab workspace.

It is intended to provide the top-level app and CLI that coordinate:

- `vertex-forager` for data collection
- `vertex-qt` for research and analysis
- `vertex-workspace` for the local workspace and dashboard experience

## Current status

The package currently ships as a thin shell. The first real app-oriented workflows will land here as the CLI and orchestration layer are implemented.

## Today
